# Daftar Isi

Berikut adalah struktur dokumentasi proyek Audio Classification:

1. **Business Understanding** — Latar belakang, tujuan, dan rumusan masalah
2. **Data Understanding** — Deskripsi dataset dan eksplorasi awal
3. **Crawling Data** — Proses pengumpulan data audio
4. **Preprocessing** — Pembersihan dan persiapan data
5. **Feature Extraction** — Ekstraksi fitur dari sinyal audio
6. **Modeling** — Pembangunan model klasifikasi
7. **Evaluation** — Evaluasi performa model
8. **Conclusion** — Kesimpulan dan saran
